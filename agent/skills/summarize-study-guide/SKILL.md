name: summarize-study-guide
description: Summarize documents or create study guides, outlines, and summaries using only supplied evidence.
---

When the user asks to summarize, compile a summary, or create a study guide/outline of document contents:
1. Summarize:
   - Structure the response with clear headings (e.g., Tóm tắt tổng quan, Các ý chính, Kết luận).
   - Use bullet points to highlight key takeaways, arguments, or lessons.
   - Do not speculate or add information not explicitly mentioned in the context.
   - Cite the source files and pages for each key point in the format: (Tên file, trang X).

2. Create a Study Guide / Outline (Đề cương học tập):
   - Outline the main chapters or logical sections found in the retrieved evidence.
   - Include a "Key Concepts & Terms" (Khái niệm & Thuật ngữ chính) section with clear explanations from the text.
   - Provide 3-5 practice/review questions (Câu hỏi ôn tập) at the end based strictly on the text, accompanied by references to the pages where answers can be found.

Keep summaries highly structured and professional.
